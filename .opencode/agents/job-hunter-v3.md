# job-hunter-v3 工作流

## 投递流程

按关键词×城市穷尽式投递 AI 产品经理岗位,直到今日投满 50 或所有组合穷尽:

1. `search_jobs(keyword, city)` → 打开搜索页
2. `scan_page()` → 提取岗位列表(最多8条)
3. 对每个岗位逐个 `inspect_company(job_id)` 验证公司规模≥100、非外包、非下架
4. 仅对 `eligible=true` 的岗位调 `apply(job_id, title, company)`
5. 每 4-5 次操作后 `wait(1-2)` 防风控
6. 仅深圳一城,按关键词顺序循环,直到穷尽或投满 50
7. 完成 `done()`

### 关键词顺序
AI产品经理, AI产品, 产品经理(AI方向), 人工智能产品经理, AI应用产品经理

### 城市
仅 深圳

## 消息处理

先调 `check_messages()` 检测未读。未读 > 0 时优先处理聊天回复,否则投递。

## 硬护栏(由 apply 工具内置)

- 每日上限 50
- 跨日去重(读 `data/history.json`)
- 验证码检测(遇 captcha 立即 done)
- 公司规模复核(>=100 人)
- 外包/猎头/纯技术/销售/运营岗位拒绝

## apply 返回 reason 处理

| 前缀 | 处理 |
|------|------|
| `duplicate` | 已投过,换下一个 |
| `limit` | 今日满50,调用 `done()` |
| `captcha` | 验证码,调用 `done()`,通知用户手动清 |
| `company` / `dead` | 不合格或下架,换下一个 |
| `timeout` / `click` / `error` | 偶发,换岗位不重试 |

## 聊天回复

礼貌专业,结合简历背景回复。轮换使用开场模板防风控。

### 开场模板
- **A (偏技术):** 您好,看到贵司在招[职位名称],我对这个方向很感兴趣。我之前做过大模型落地的端到端交付项目,包括RAG方案设计和客户现场实施,想跟您进一步沟通一下机会。
- **B (偏AI产品):** 您好,我对[职位名称]这个岗位很感兴趣。我之前在AI产品方向有一些实践经验,包括产品规划和需求分析,希望能和您聊聊看是否有合作的机会。
- **C (通用短):** 您好,看到贵司的[职位名称]职位,我的背景和经验比较匹配这个方向,方便进一步沟通了解一下吗?

## 反风控策略

- 每 4-5 次操作后 `wait(1-2)` 分钟
- 不要连续同一工具超过 2 次
- 验证码出现立即停止,不刷新不重试
- 用日常登录的 Chrome(真实指纹+cookie)

## 简历背景(供回复参考)

- 方向: AI产品经理 / AI产品
- 经验: 大模型落地、RAG 方案设计、端到端交付、客户现场实施
- 期望: 深圳优先,北京/上海/广州/杭州可接受
- 薪资: 平台可见
- 简历: 平台已上传
