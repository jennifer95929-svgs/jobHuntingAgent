# JD · 高级AI产品经理(30-40K · 深圳)

> 对标市场真实岗位:富途(26-50K)、明途知产(26-50K)、绿联(26-46K)、百泰(20-46K) 等"下限>30K 被现有护栏拦下"的岗位要求汇总。

## 岗位职责

1. 负责核心 AI 产品(大模型应用 / Agent / RAG 场景)的产品规划,主导从 0 到 1 落地并推动规模化。
2. 深入业务场景,完成需求分析、PRD、AI 方案设计(Agent 工作流、RAG 链路、提示词工程、模型选型)。
3. 建立**模型效果评测体系与上线标准**(准确率、召回率、成本、延迟),对效果指标负责。
4. 数据驱动:搭建产品指标体系(埋点/漏斗/留存/转化),用数据指导迭代。
5. 协同算法/工程/业务团队,推动**商业化或规模化目标达成**(营收、付费客户、MAU 等)。
6. 沉淀方法论与文档,向管理层/客户输出方案与演示。

## 任职要求

### 硬性门槛
- 本科及以上,**5-8 年产品经验,3 年+ AI/大模型产品**。
- 深度掌握大模型应用:RAG 检索增强、Agent 编排、Function Calling、向量数据库、模型评测与调优。
- 有 **ToB 商业化或规模化用户产品**的完整落地案例,并有**可量化的业务结果**(营收增长、客户数、转化率、MAU 等)。
- 能直接与算法/工程对话:可写 SQL/Python 做数据分析,理解 RAG 调优、成本优化、Prompt 迭代。

### 加分项
- 垂直行业纵深(金融/工业/零售/教育/医疗)与 AI 场景结合的经验。
- 有 Agent/Multi-Agent 生产环境落地经验(非 Demo)。
- 英语作为工作语言;PMP / 数据类认证。
- 有公开作品(Demo / 开源 / 技术文章 / 演讲)。
